⛧ TERMUX / ANDROID

Mais poder com Python.

Consulte o portal e use ferramentas locais pelo Termux, sem instalar bibliotecas extras.

Instalar no Termux

Execute uma vez no Termux. O script usa apenas a biblioteca padrão do Python.

pkg install python curl -y
mkdir -p ~/parabellum-cli
cd ~/parabellum-cli
curl -fL https://raw.githubusercontent.com/k9dxx/parabellum-panel/main/tools/pblm.py -o pblm.py
python pblm.py --help

Os comandos de consulta acessam somente dados públicos. Esta ferramenta não coleta senhas do portal nem consulta anotações pessoais.

COMANDOS.

Ver contagens e endereço do portal.

python pblm.py status

Buscar integrantes publicados.

python pblm.py membros --buscar k9

Consultar comunicados.

python pblm.py noticias

Consultar encontros publicados.

python pblm.py agenda

Ver materiais disponíveis e seus identificadores.

python pblm.py materiais

Baixar o kit visual na pasta atual.

python pblm.py baixar kit-visual

Guardar uma cópia dos dados públicos do portal.

python pblm.py backup-publico

Conferir a estrutura de um rascunho antes de publicar.

python pblm.py validar conteudo.json

Gerar uma senha local com aleatoriedade segura.

python pblm.py senha --tamanho 24

Mostrar o endereço da área pessoal.

python pblm.py pessoal

O Python roda no seu Termux. O GitHub Pages não executa Python no servidor. Não coloque arquivos pessoais, senhas ou tokens no repositório público.
