Entrar com sua conta GitHub

A edição abre no GitHub, onde o acesso de escrita é verificado. Depois que a alteração é salva na branch main, o GitHub Pages publica o conteúdo.

EDITAR CONTEÚDO NO GITHUB ↗VER PEDIDOS DE ENTRADA ↗

01 / Membros

Na lista membros, adicione nome, cargo e descricao. Use o identificador de um cargo existente. Instagram é opcional.

02 / Notícias

Na lista noticias, adicione id único, titulo, categoria, data no formato AAAA-MM-DD, resumo e paragrafos.

03 / Galeria

Adicione as imagens na pasta assets/artes e registre titulo, categoria e arquivo na lista galeria.

ABRIR PASTA DE ARTES ↗
